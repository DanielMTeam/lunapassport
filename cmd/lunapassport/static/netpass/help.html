Что такое .NET Passport?

Одна из первых попыток в единую систему аутентификации от Microsoft, которая ныне известна как "Учётная запись Microsoft"

Какие преимущества даёт данная технология в оригинале?

Оно позволяло автоматизировать вход на сайт, сохранять персональную информацию и платежные данные для упрощения покупок в интернет-магазинах, поддерживающие данную реализацию

А что это даст здесь?

Если скачаете официальное приложение, то в нём будет совершён автоматический вход и Вы получите множество других возможностей

Какие ОС Windows поддерживаются?

.NET Passport поддерживает только Windows XP

Как отвязать .NET Passport?

Вы можете отвязать его самостоятельно через "Учётные записи пользователей" либо в настройках аккаунта в самом LunaStore
